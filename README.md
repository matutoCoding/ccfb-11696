# 建筑立面投光设计与夜景预览系统

浏览器内运行的城市亮化工程设计工具：参数化立面建模、灯具布置、照度计算、夜景伪彩/光效预览，全程 TypeScript + three.js，数据保存在浏览器本地。

## 启动

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 生产构建
npm test           # 23 项数值/逻辑测试
```

## 六大页面

| 页面 | 功能 |
| --- | --- |
| 项目列表 | 新建/重命名/复制/删除，localStorage 持久化，JSON 导入导出 |
| 立面建模 | 层数/层高/开间/窗墙比参数化生成，横向腰线、竖向线条、凸窗 |
| 灯具布置 | 投光灯/洗墙灯/点光源，TransformControls 拖拽 + 数值精确调参，分组 |

| 设置 | 发光效率/维护系数/反射率/网格间距/LPD 限值、分组管理、数据备份 |

## 照度引擎（核心）

代码在 `src/core/photometry.ts`，全部为解析公式、无数值积分近似：

```
E = Σ I(θ)·cosα / r²
```

- **投光灯**：`I(θ) = I₀·cosⁿθ`，光束角 β（50% 光强全角）反解 `n = ln0.5 / ln cos(β/2)`；
  半球通量积分 `Φ = 2π·I₀/(n+1)` 归一化得 `I₀ = (n+1)Φ/(2π)`
- **点光源**：各向同性 `I = Φ/(4π)`
- **洗墙灯**：沿发光段离散 N 个朗伯发光点，单点 `I(θ)=I₀·cosθ`，`I₀ = Φᵢ/π`
- **有效通量**：`Φ = 功率 × 发光效率 × 维护系数`
- **玻璃**：直射照度照常计算但只显示 `E·ρ` 反射伪彩，不进入照度统计

### 准确性保证

`src/core/photometry.test.ts` 中测试用例与引擎**平行独立推导**手算公式（不共享代码），断言：

- 单灯垂直入射、斜入射（三因子齐全）、俯仰偏转各场景，引擎 vs 手算相对误差 `< 1e-12`
- 配光半球通量积分守恒（误差 < 0.2%）、距离平方反比、多灯线性叠加
- 照度页"手算对照"卡片实时显示当前项目第一台投光灯的误差（实测 ~1e-13%，承诺 < 1%）

开发过程中该测试曾抓出一个真实 bug：I₀ 归一化误写成 `(n+2)` 导致系统性偏高 6.75%，已修正为 `(n+1)`。

### 刷新一致性保证

- 几何、灯具、场景全部为可序列化参数，经 zustand persist 写入 localStorage
- 渲染器/相机/控制器参数写死，ACES 色调映射固定
- 全代码库禁止 `Math.random`；夜景周边建筑剪影使用 mulberry32 种子随机（种子=项目 id+名称），同项目永远同一布局

## 坐标系约定

米制；主墙位于 z=0，灯在 z<0 一侧；面片法线指向受光面（主墙 +Z）；
灯具零位光轴 +Z，pitch 为仰角（向上为正），yaw 绕 Y 轴。

## CSV 导出

灯具清单（含全部/当前场景两个版本）与照度报表均带 UTF-8 BOM，Excel 直接打开中文不乱码。
